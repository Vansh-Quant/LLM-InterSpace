# LLM InterSpace\n\n> **The models stay independent. The experience becomes collective.**\n\nInterSpace is a local-first coordination and verified-memory layer for independent LLM agents. Agents keep private reasoning locally; only structured, checkable outputs enter shared InterSpace.\n\n## Current build\n\n- FastAPI gateway + central SQLite store\n- Agent registration, status and heartbeat\n- Structured events and append-only audit log\n- Contract publishing, versioning and deterministic diffing\n- Contract subscriptions and cross-device notifications\n- Agent-to-agent structured messages\n- Verified Experience records with lifecycle state machine\n- Verification records and controlled state transitions\n- Project State + project/shared-agent knowledge\n- Precedence engine\n- Sandboxed pytest QA execution\n- Python agent runtime wrappers\n- Ollama chat integration with structured-output support\n- Local private agent memory\n- Optional Ollama embeddings adapter\n- React/Vite live dashboard\n- Complete contract-drift → message → QA → verified-memory demo\n- Automated tests\n\n## Run\n\nPowerShell:\n\n    .\.venv\Scripts\Activate.ps1\n    pip install -r requirements.txt\n    pytest -q\n    uvicorn main:app --host 0.0.0.0 --port 8000\n\nComplete demo:\n\n    python demo/full_demo.py --gateway http://127.0.0.1:8000\n\nDashboard:\n\n    cd dashboard\n    npm install\n    npm run dev\n\nSet a remote gateway for the dashboard:\n\n    $env:VITE_INTERSPACE_API="http://10.162.128.8:8000"\n    npm run dev\n\n## Complete demo flow\n\nBackend V1 → V2 contract drift → Frontend notification → agent message → Experience OBSERVED → TESTED → pytest QA → VERIFIED → Verification record → Experience retrieval.\n\n## Multi-device\n\nOnly the gateway host owns SQLite. Other devices communicate through HTTP. Same-LAN/hotspot operation is the current network mode. Remote-device networking is intentionally a later deployment layer.\n\n## Verification lifecycle\n\nUNVERIFIED → OBSERVED → TESTED → VERIFIED → REUSED → RECONFIRMED\n\nTESTED → REVIEW → REVISED / INVALIDATED\n\n## Precedence\n\n1. Current Verified Project State\n2. Project-specific Verified Knowledge\n3. Verified Historical Experiences\n4. Shared Agent Knowledge\n5. Foundation-model general knowledge\n\n## Repository layout\n\n    interspace/core/          gateway, contracts, QA, precedence\n    interspace/agents/        runtimes, Ollama, private memory\n    interspace/communication/ events, messages, notifications\n    interspace/audit/         audit models + verification state machine\n    interspace/retrieval/     Experience retrieval + embeddings adapter\n    demo/                     runnable demo scenarios\n    dashboard/                React/Vite dashboard\n    tests/                    pytest suite\n
